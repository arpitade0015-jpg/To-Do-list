# To-Do List Management System

A simple **To-Do List Management System developed using Python**. This project is designed for beginners and demonstrates basic Python programming concepts such as functions, lists, dictionaries, loops, conditional statements, and user input.

## Features

The program provides the following features:

* Add a new task
* View all tasks
* Mark a task as completed
* Delete a task
* Search for a task
* Exit the program

## Project Modules

| Module | Function      | Description                    |
| ------ | ------------- | ------------------------------ |
| 1      | Add Task      | Adds a new task                |
| 2      | View Tasks    | Displays all tasks             |
| 3      | Complete Task | Marks a task as completed      |
| 4      | Delete Task   | Deletes a task                 |
| 5      | Search Task   | Searches for a particular task |
| 6      | Exit          | Exits the program              |

## How to Run

1. Install Python on your computer.
2. Open **Python IDLE**.
3. Open the project Python file.
4. Save the file with a `.py` extension.
5. Press **F5** or select **Run → Run Module**.
6. The To-Do List menu will appear in the Python Shell.
7. Enter the number corresponding to the required operation.
